# Demo Page

Ayatori Nexus includes a static GitHub Pages site under `docs/`.

After pushing the repository, publish it from GitHub:

1. Open the repository on GitHub.
2. Go to **Settings** -> **Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select branch **main** and folder **/docs**.
5. Save and wait for GitHub Pages to finish publishing.

The demo URL should become:

```text
https://yuxuansun123.github.io/cli-model-switcher/
```

Use that URL in hackathon or competition forms.

You can also upload these assets to the competition form:

- `docs/assets/demo-preview.png` as a project screenshot.
- `docs/assets/ayatori-logo.png` as the square project logo.
